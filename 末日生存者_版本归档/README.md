## 版本命名说明

- 早期版本（v1.0-v1.4）：使用"第X版"命名方式
- 后期版本（v1.6.0+）：改为语义化版本号命名，并标注Alpha阶段

## 缺失版本说明

- v1.5（第五版到第六版之间）：未找到独立版本包，可能直接并入了v1.6.0的开发
- v1.7.x系列：规划中但尚未完成的版本（详见更新计划）

## 废弃版本

废弃版本目录包含：
- 末日生存者（旧版）：早期开发版本
- 末日生存者（测试版）：测试用版本
